# 哈希表（Hashmap）

*哈希表* 可以把一个值和某个特定的键关联起来。
你在其他语言里可能见过它的其他名字：C++ 里的 [*unordered map*](https://en.cppreference.com/w/cpp/container/unordered_map)、
Python 里的 [*dictionary*](https://docs.python.org/3/tutorial/datastructures.html#dictionaries)，
或者其他语言里的 *关联数组*（associative array）。

这就是我们之前讲向量时提到的另一个有用的数据结构。
