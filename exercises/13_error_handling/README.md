# 错误处理

大多数错误并没有严重到必须让整个程序停止。
有时候，函数失败的原因是你很容易理解和应对的。
例如，你想打开一个文件，但这个操作因为文件不存在而失败了，
这时你可能想创建这个文件，而不是终止整个进程。
