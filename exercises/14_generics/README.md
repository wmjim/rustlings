# 泛型（Generics）

泛型讨论的是如何把类型和功能推广到更普遍的情形。
它在很多方面都非常有助于减少代码重复，但也可能带来一些比较复杂的语法。
也就是说，使用泛型时必须特别小心地规定：一个泛型类型究竟在哪些类型上才算有效。
泛型最简单、最常见的用法就是类型参数（type parameter）。
