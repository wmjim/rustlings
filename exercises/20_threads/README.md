# 线程（Thread）

在大多数现代操作系统中，程序的代码运行在进程（process）之中，
而操作系统会同时管理多个进程。
在你的程序内部，同样可以有同时运行的独立部分。
用来运行这些独立部分的功能就叫线程（thread）。
